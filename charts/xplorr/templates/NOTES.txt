{{ if .Values.installOpenCost -}}
OpenCost was installed with this release, reporting as CLUSTER_ID
"{{ .Values.clusterName }}". It takes a minute or so to come up. Wait for it
before running anything, because a Service with no ready endpoints refuses
the connection rather than waiting:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/opencost
{{- else }}
OpenCost was not installed by this release. The collector reads
{{ include "xplorr.openCostUrl" . }}, and waits for it to answer before
sending anything.
{{- end }}

The collector runs on the schedule {{ .Values.xplorr.schedule }} (UTC), so the
first send is otherwise up to an hour away. Run it now instead:

  kubectl -n {{ .Release.Namespace }} create job xplorr-first-run \
    --from=cronjob/{{ include "xplorr.fullname" . }}-collector

  kubectl -n {{ .Release.Namespace }} logs -f job/xplorr-first-run

A run that worked ends with "sent to Xplorr". The console then moves this
cluster from "Waiting for collector" to "Receiving", which can take a minute.

{{ if .Values.xplorr.ingestToken -}}
The ingest token is in this release's values, which means it is in Helm's
release Secret and in whatever holds your values file. To keep it out of both,
put it in a Secret under the key `token` and reinstall with
--set xplorr.existingSecret=<name> instead.
{{- end }}

Cost is reported by namespace, controller, pod and label, with idle capacity
kept separate. OpenCost prices at public on-demand rates until you give it
your cloud pricing details, so reserved, savings plan and spot discounts will
not show until you do:

  https://www.opencost.io/docs/configuration/
